# SM100 / TCGEN05 Starting Recipe

Start from the single-CTA TMEM kernel in
`../examples/gemm_sm100/gemm_tcgen5mma.py`. Do not invent a new TMEM protocol.
Do **not** treat `../examples/flash_attention_sm100/gqa_bwd_bshd.py` as a
working TCGEN05 pattern: its `C` is not TMEM.

## Single-CTA TMEM GEMM

Eager factory, `T.const` shapes, TMEM accumulator, explicit-async
`T.tcgen05_gemm` + `T.mbarrier_wait_parity`:

```python
@tilelang.jit(
    pass_configs={
        tilelang.PassConfigKey.TL_DISABLE_TMA_LOWER: True,
        tilelang.PassConfigKey.TL_DISABLE_WARP_SPECIALIZED: True,
    },
)
def matmul(A, B, block_M, block_N, block_K, trans_A, trans_B,
           in_dtype, out_dtype, accum_dtype, num_stages, threads):
    M, N, K = T.const("M, N, K")
    A: T.Tensor((M, K) if not trans_A else (K, M), in_dtype)
    B: T.Tensor((K, N) if not trans_B else (N, K), in_dtype)
    C = T.empty((M, N), out_dtype)

    with T.Kernel(T.ceildiv(N, block_N), T.ceildiv(M, block_M), threads=threads) as (bx, by):
        A_shared = T.alloc_shared((block_M, block_K), in_dtype)
        B_shared = T.alloc_shared((block_K, block_N), in_dtype)
        C_tmem = T.alloc_tmem([block_M, block_N], accum_dtype)  # rank ≥ 2
        mbar = T.alloc_barrier(1)
        C_local = T.alloc_fragment((block_M, block_N), accum_dtype)
        C_shared = T.alloc_shared((block_M, block_N), out_dtype)

        for k in T.Pipelined(T.ceildiv(K, block_K), num_stages=num_stages):
            T.copy(A[by * block_M, k * block_K], A_shared)
            T.copy(B[bx * block_N, k * block_K], B_shared)
            T.tcgen05_gemm(
                A_shared, B_shared, C_tmem, trans_A, trans_B,
                mbar=mbar, clear_accum=(k == 0),
            )
            T.mbarrier_wait_parity(mbar, k % 2)

        T.copy(C_tmem, C_local)
        T.copy(C_local, C_shared)
        T.copy(C_shared, C[by * block_M, bx * block_N])
    return C
```

The shared shapes and copies above are the NT layout used by that example
(`trans_A=False`, `trans_B=True`: `B_shared` is `(block_K, block_N)` and `B`
is indexed `[N, K]`). When those flags differ, shared shapes and copies must
follow `../examples/gemm_sm100/gemm_tcgen5mma.py` — do not keep these
hard-coded extents.

Rules from this recipe:

- `T.alloc_tmem` rank ≥ 2. Same warp allocates and deallocates.
- `T.tcgen05_gemm` is explicit-async. `mbar=None` is legal for an
  intermediate issue; this example passes a barrier and waits every K step.
- `T.gemm(..., mbar=...)` is the **synchronous** path and inserts
  `mbarrier_wait_parity` for you. Use that only when you do not need manual
  overlap.
- `TL_DISABLE_WARP_SPECIALIZED` is required on this single-CTA example.
- `T.Kernel` here — no cluster. 2CTA kernels switch to `T.ClusterKernel`.

## Common Mistakes

- Passing `cluster_dims=` to `T.Kernel` — use `T.ClusterKernel`.
- Rank-1 TMEM — `T.alloc_tmem` asserts rank ≥ 2.
- Copying TMEM `C` as if it were a fragment without the block-scaled layout
  annotation (`T.make_blockscaled_gemm_layout` + `T.annotate_layout`).
- Using `sf_a_id` / `sf_b_id` — those kwargs are gone.
- Citing SM100 attention backward examples as TCGEN05 templates when `C` is
  not TMEM.
